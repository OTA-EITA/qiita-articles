# slide-skills-compare

同じ原稿・同じ依頼文・同じ答えで、スライドを作るスキルを比べたときの計測スクリプト。

## 条件

- 原稿: [public/ingress-nginx-nginx2shell.md](../../public/ingress-nginx-nginx2shell.md) の本文（前付けを除く。約 6,700 字）
- モデル: Sonnet 5.5（Claude Code のサブエージェント。スキルごとに別のフォルダ・別の会話）
- 依頼文（全部同じ）:

```
資料元.md の内容をもとに、社内の勉強会で発表するスライドを作ってください。
- 資料元.md にない情報は足さないでください
- 順番と見出しは、資料元.md のとおりにしてください
- できあがったファイルは、このフォルダに保存してください
```

- スキルが質問してきたときの答え（全部同じ。人は答えない）:
  - 場面と聞き手: 社内のエンジニア向け勉強会。参加者は Kubernetes を触っているエンジニア
  - 見せ方: 発表者が話しながら見せる
  - 長さ: 発表 20 分くらい。枚数はおまかせ
  - 素材: 資料元.md だけ。画像は資料元.md にある 1 枚だけ
  - 必ず入れる・出さない: 特になし
  - 案を複数出して選ばせる流れでは、いちばん最初の案を選ぶ
  - 構成案などの確認には「それで進めて」

## 数え方

```sh
node measure-html.mjs <名前> deck.html [スライドのセレクタ]   # HTML のデッキ（Node 22 以降と Chrome）
python3 measure-pptx.py <名前> deck.pptx                      # pptx のデッキ（python-pptx）
```

- 文字数: 1 枚の中の文字（空白を除く）。表・コードも含む
- 箱: スライドの 1〜50% の大きさで、塗りか枠があり、角丸（6px 以上）か影が付いた要素。pptx は roundRect か影の付いた塗りの図形
- 太字: 見出し以外の太字（HTML は 48px 未満で太さ 700 以上、pptx は 28pt 未満の太字の run）。HTML と pptx で数え方が違うので、同じ形式どうしで比べる
